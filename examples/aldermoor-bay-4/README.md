# Aldermoor Institute, Bay 4 (fictional)

A made-up automated screening lab, built from instruments you can actually buy. The facility, its records and
everything that happens in it are invented. The evidence contradicts itself on purpose, the way real lab records do:

| Contradiction | Sources in conflict |
| --- | --- |
| RDR-02 is registered "In service" but has not answered for 11 days | inventory, network scan, facilities note |
| CFG-01 is on the drawing and the network, not on the asset register | floor plan, network scan, inventory |
| INC-01 is registered at 44 plates but reports 22 (one of two cassettes fitted) | inventory, network scan |
| Door D-3 is narrower than the AMR needs | floor plan, facilities note |
| Read and imaging take longer than the SOP says | SOP-117, run log |
| SOP-117 assumes the arm reaches the imager; the rail stops in the bay | SOP-117, floor plan |

`evidence/run-log.csv` is generated by `npm run gen:example` from a fixed seed.

## The equipment

Product names belong to their manufacturers. SDL is not affiliated with or endorsed by any of them. The 3D models
are procedural approximations with no logos, not manufacturer CAD.

**Everything about how these units behave here is fictional:** the failures, MTBF and MTTR figures, cycle times and
run logs say nothing about the real products. RDR-02's lamp failure is a plot device. Network addresses are invented,
and protocols describe this imaginary site's integration layer, so an instrument shown on SiLA2 or OPC-UA may need a
gateway in practice.
